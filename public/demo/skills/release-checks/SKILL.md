# Release checks — v2

Illustrative DeltaNet shared skill. Sample workflow; not an operational runbook.

Owner: Engineering
Revision approved by: Omar Alharbi
Change: Add saved-card payment verification following the checkout incident review.

## When to use
Before clearing a checkout release.

## Procedure
1. Complete a new-card payment in the test environment.
2. Complete a saved-card payment in the test environment.
3. Record the environment, release version, results, and evidence links.
4. Flag failed or unavailable checks. Do not describe an unverified check as passed.
5. Return the release brief to the person reviewing the release.

Publishing this skill shares the procedure, not Omar's private conversation or credentials.
