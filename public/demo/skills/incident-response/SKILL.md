# Incident response

This is a presentation fixture for the DeltaNet demo, not an installed or executing skill.

1. Read the incident brief, release details, and linked runbook. Identify the failure and prepare a fix for the release owner to review.
2. Obtain the release owner's deployment approval. After deployment, verify a production checkout. Record the observed result in the incident issue and share that result with Customer Success.
3. Prepare a plain-language customer update from the verified result. Obtain Customer Success approval before sending. Return the notification outcome to the requesting agent.

Complete when recovery is verified and the approved customer update is sent. Share the task brief, source references, and outcomes; keep each person's unrelated conversation private.
